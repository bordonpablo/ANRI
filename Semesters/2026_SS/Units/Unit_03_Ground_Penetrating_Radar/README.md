# Unit 03 — Ground Penetrating Radar (GPR)

## Overview

This unit covers the principles and practice of Ground Penetrating Radar (GPR), an active electromagnetic method used to image the shallow subsurface. Topics include wave propagation theory, instrumentation, field acquisition strategies, data processing, and interpretation. Applications span environmental, engineering, archaeological, and resource investigation contexts.

---

## Learning Objectives

By the end of this unit, students will be able to:

- Explain the physical principles of GPR and the factors controlling resolution and depth
- Plan, execute, and process a GPR field survey
- Interpret radargrams and assess GPR suitability for a given investigation problem

---

## Key Concepts

- Electromagnetic wave propagation in earth materials
- Instrumentation, antenna selection, and acquisition modes
- Processing workflow and radargram interpretation
- Typical applications in environmental and engineering contexts
